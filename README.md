# RxVault — Prescription Master

A Progressive Web App (PWA) for viewing and managing medical prescriptions by Dr. Imran Khan Muhammadi

## 🩺 About

RxVault is a curated collection of medical prescriptions organized by specialty for educational and clinical reference. Built as a Progressive Web App, it works offline and can be installed on any device.

**Doctor:** Dr. Imran Khan Muhammadi  
**Graduation:** Medical Faculty, Class of 2026

## ✨ Features

- 📱 **Installable PWA** — Add to home screen for app-like experience
- 🔄 **Auto-sync** — Automatically fetches latest prescriptions from GitHub
- 📴 **Offline support** — Works without internet after first load
- 🔍 **Search** — Find prescriptions by name, medication, or condition
- 📁 **Categories** — Browse by medical specialty
- 🖼️ **Disease images** — Visual reference for each condition
- 💊 **Detailed prescriptions** — Full medication info with dosages

## 📦 Installation

### For Users

1. Visit the live URL above
2. Tap the ⋮ menu (three dots) in your browser
3. Select "Install app" or "Add to Home Screen"
4. RxVault will appear as an app on your device
